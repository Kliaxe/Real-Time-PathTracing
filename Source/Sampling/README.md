# Spatiotemporal blue noise

This module owns a `64 x 64 x 32` `VK_FORMAT_R8_UINT` texture array generated by
`Scripts/generate_blue_noise.py`. No source code or texture data from the
Tellusim or NVIDIA implementations is included.

The generator builds each spatial layer with periodic void-and-cluster ranking.
Successive layers start from the flipped preceding pattern with a deterministic
exchange before relaxation. A fixed layer ordering and rank complement were
selected afterward to suppress temporal frequencies; those operations preserve
the spatial spectrum of every layer.

## Shared path sampling

Both reference PT and ReSTIR PT read this volume directly through
`Source/ShaderIncludes/PathTracing/Sampling.hlsli`. Each scalar coordinate has
an address consisting of the original pixel, RNG frame, bounce, estimator
purpose, and dimension. This replaces the former first-PCG-output seed trick.

Separate streams cover environment NEE, emissive NEE, BSDF sampling, and
roulette. All BSDF groups consume one lobe selector and two direction
coordinates. NEE branches cannot advance BSDF dimensions. ReSTIR light-point
candidates have stable dimension indices even when earlier candidates are
rejected. Candidate selection and reuse selection continue to use independent
integer RNG streams.

Toroidal texture translations vary by dimension, screen tile, and 32-frame
epoch. They remain fixed inside an epoch to retain temporal ordering. A
dimension-specific Cranley-Patterson rotation randomizes the full sample
domain each epoch; fine per-pixel jitter supplies the remaining bits. Thus the
same 32 coarse ranks do not remain a pixel's only possible strata forever.
The final conversion uses the top 24 bits and returns values strictly below 1.

These are scalar STBN dimensions with independent scrambles, not a jointly
optimized vector STBN texture or a high-dimensional low-discrepancy sequence.
Tile boundaries and epoch changes can weaken spectral properties. The original
asset metrics above describe the untransformed volume, not final sample values
or rendered radiance. Do not claim the final ReSTIR output retains an STBN
spectrum after path transport, reservoir reuse, and denoising.

## Replay and NRD

ReSTIR stores the original packed pixel and full 32-bit RNG frame in
`samplePixel` and `sampleFrame`. These reclaim the unused suffix seed and NEE
PDF fields, preserving the 64-byte packed reservoir stride. All endpoint paths
preserve the sampling origin, and every replay stream uses it rather than the
receiving pixel or current frame. Reservoir data from an older shader version
is incompatible; rebuild and restart after changes.

ReSTIR's RNG frame now advances independently of reuse-history resets, matching
the reference tracer's behavior. Both NRD paths use 5x5 hit-distance
reconstruction by default because one primary BSDF lobe is sampled per frame.
Raw and accumulated reference PT remain available for estimator comparisons;
NRD output is a reconstructed image, not a ground-truth estimate.

## Verification

Build `RtptPathSamplingTests` and run `ctest --preset x64-Debug -R PathSampling`.
The GPU test checks the actual sample range, low-frequency power of all three
primary BSDF dimensions, full-width origin storage through separate dispatches,
endpoint preservation, and replay identity. Pass a binary output path to the
test executable to export its samples for further analysis.

Headless runs support `--resolve-mode off|accumulate|denoise`. For identical-path
comparison, use `--renderer restir-pt --restir-reference`; this disables reuse,
candidate selection, and light tiles. Compare against `--renderer path-tracer`
at the same scene, dimensions, frame count, and resolve mode. The reference
switch rejects denoising because that comparison must use raw or accumulated
radiance.

The September 2026 GPU measurements found spatial low/mid power ratios of
0.052, 0.043, and 0.048 for the first three BSDF dimensions, versus about 1 for
white noise. Temporal ratios over 64 frames were 0.868, 0.537, and 0.892.
Cornell Box at frame 1 and Bunny Glass at frame 33 produced byte-identical HDR
and PNG captures between reference PT and ReSTIR reference mode. These are
focused checks, not a proof of estimator unbiasedness or universal NRD quality
improvement.

The design follows the scalar sampling use described in
[NVIDIA's STBN overview](https://developer.nvidia.com/blog/rendering-in-real-time-with-spatiotemporal-blue-noise-textures-part-1/).
That overview also cautions that STBN targets low sample counts and low
dimensions. No NVIDIA code or textures were added.
